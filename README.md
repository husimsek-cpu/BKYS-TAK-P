# BKYS-TAK-P

Basit bir ürün takip uygulaması (vanilla HTML/CSS/JS).

## Çalıştırma

```bash
python3 -m http.server 8000
```

Tarayıcıdan aç:

- http://localhost:8000

## Özellikler

- Ürün ekleme
- Stok +1/-1 güncelleme
- Kritik stok durum etiketi
- Ürün silme
- Verileri `localStorage` ile saklama
