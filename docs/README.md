# Dokümantasyon

Bu klasör, BKYS-TAK-P projesi ve uygulamaları için detaylı dokümantasyon içerir.

## 📚 İçerik

### Mevcut Dokümantasyon

- [Ana Sayfa](../README.md) - Proje genel bakış
- [Katkıda Bulunma](../CONTRIBUTING.md) - Katkı rehberi
- [Web Portalı](../index.html) - HTML erişim portalı

### Gelecek Dokümantasyon (Yakında)

- **Kurulum Rehberi** - Detaylı kurulum adımları
- **Kullanım Kılavuzu** - Uygulama kullanım örnekleri
- **API Dokümantasyonu** - API referansı (varsa)
- **SSS** - Sıkça sorulan sorular
- **Troubleshooting** - Sorun giderme rehberi

## 🔍 Navigasyon

Her dokümantasyon dosyası şunları içermelidir:
- Net başlıklar ve alt başlıklar
- İçindekiler bölümü
- Kod örnekleri
- Görsel açıklamalar (gerektiğinde)

## 📝 Dokümantasyon Ekleme

Yeni dokümantasyon eklemek için:

1. Bu klasörde yeni bir .md dosyası oluşturun
2. Yukarıdaki listeyi güncelleyin
3. Ana README.md'ye link ekleyin
4. Pull request açın

## 🤝 Katkı

Dokümantasyon katkılarınız çok değerlidir! Daha iyi dokümantasyon, daha erişilebilir proje demektir.
